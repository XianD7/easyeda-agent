# 设计取舍参考

按当前需求选读，记录会改变电路、成本或制造方式的取舍及依据。已有授权内自主决定常规事项；
只有缺失信息会实质改变目标、预算或制造条件时才询问用户。无需逐条确认本清单。
设计流程见 [design-flow.md](design-flow.md)；具体器件资料、制造约束和本次需求优先于历史样板。

## 叠层与层数(Stackup)

### 2 层 vs 4 层（及以上）层数

- 按布线密度、信号边沿/阻抗、回流连续性、电流、尺寸及成本选择层数。简单低密度板可从两层评估；
  需要完整参考面或更高密度时评估四层及以上。不因存在 GND、3V3 等多个网络就增加层数。
- 两层板可以承载多个电源域。某次分区铺铜导致孤岛或 No-Connection，说明该次布局、布线或工具
  处理需要修正，不能推导为“两层板物理上不可行”。增加层数也不保证网络全部连通。
- 用户明确要求的层数是输入约束；无法满足时说明具体冲突并比较方案。各候选仍需回读、DRC 和连通检查。

### VCC/电源内层类型：PLANE（内电层） vs SIGNAL 分区铺铜

- 先确定实际铜形状、网络归属、参考面与回流，再选择宿主支持的表示。`PLANE` 是 EDA 层类型，
  不能仅凭负片/正片或层名判断电气质量；SIGNAL 层上的完整地铜也可构成参考面。
- 多个电源域可用走线、局部铜或分区内层实现，不自动要求每个网络独占一层。
  若信号以该层为参考，检查其是否跨越分割；不同网络保持绝缘距离与实际连通性。
- 当前工具对 PLANE 的创建/编辑限制按 [PCB 规则](pcb-design-rules.md)核实。
  [历史 API 配方](pcb-layout-conventions.md) §7.7 仅描述对应宿主与用例，不代表普遍物理限制。

## 接地策略(Ground Strategy)

### 完整参考面与功能分区

- 一般优先连续地参考面并按功能安排器件和回流。模拟、数字、RF 或功放共存，本身不构成割地理由。
- 分地需有器件参考设计、回流或隔离需求支持。确定跨域信号、返回路径及连接位置后，再决定是否使用
  0Ω、电阻、磁珠或其他连接方式；不能从地网数量直接推导“四层全 SIGNAL + 单点桥地”。
- 需要电气隔离的地不得为满足布局惯例而短接。PLANE 是否支持分区属于具体宿主/API 能力问题。
  三块开发板的不同做法仅作案例，见 [布局约定](pcb-layout-conventions.md) §7.9。

### 外层铺铜与线宽

- 线宽、铜厚、过孔数量按工作/峰值电流、允许温升、压降和制造能力确定；受控阻抗信号按实际叠层计算。
  局部电源铜可改善载流或散热，也可能挤占回流路径，需检查最终铜形状。
- `pcb net-classes`、`pcb check` 可检查工具的宽度建议。网名推断的角色、6/10/15/20 mil 阶梯及
  历史板宽度只是候选依据，不能替代电流与阻抗设计，也不能把工具内建议当作已写入原生 DRC 规则。
- API、铺铜顺序与规则覆盖范围见 [PCB 配置](pcb-config.md)、[PCB 规则](pcb-design-rules.md)。

## RF 与天线禁布区(RF Keepout)

- 按确切模组/天线型号的数据手册确定禁铜、禁布件、板边位置、净空和地平面要求。
  需要全层禁铜的 PCB 天线，应覆盖实际叠层及内电层；不能只检查顶层。
- `WROOM`、`WROVER` 或 `ANT*` 名称不足以确定规则：不同天线结构可能需要地平面、匹配或指定安装面。
  避免把某类模组的禁铜区域套到整颗模组或其他天线上。
- 使用 `pcb check` 时核对其天线识别和覆盖范围。启发式与器件资料冲突时保留差异并修正模型/工具，
  不以检查通过代替射频设计，也不编造豁免结果。

## 接口取向(Connector Orientation)

### USB-C 正反插与实际引脚

- 普通 USB 2.0 Type-C 数据母座应实现两种插入方向的数据连接；按实际连接器 pin map 核对
  A6/B6 为 D+、A7/B7 为 D−，包含封装内部已合并引脚的情况。CC、供电角色和保护另按接口要求设计。
- 充电专用口是否省数据由产品需求决定。布线工具暂时不支持交叉或过孔，不构成省略一侧数据脚的理由；
  应调整布局/连接器方案，或如实报告未完成。

### USB 架构与下载恢复

| 方案 | 适用条件与代价 |
|---|---|
| 板外下载接点 | 原型或配套治具可接受时减少板上器件；保留确切芯片需要的启动、复位、通信与供电接点。 |
| 纯原生 USB | 确切芯片、ROM/固件及工具链满足下载和运行接口需求时可省桥接器；核实失效恢复途径。 |
| USB 转串口桥 | 需要独立串口、工具兼容性或独立于应用 USB 的调试路径；增加器件与面积。 |
| HUB 或独立双接口 | 确需原生 USB 与串口同时可用时评估；增加成本、供电和信号完整性工作。 |

- 区分 USB OTG、USB Serial/JTAG、应用 CDC 与 ROM 下载支持；不同芯片/变体不能互套。
  桥接器是否有价值取决于调试与恢复需求，不能仅因芯片有 USB 就判为冗余。
- 串口自动下载电路按芯片启动时序和工具要求选用。原生 USB 的自动复位能力也需核实；
  固件禁用接口或配置改变后的恢复方式应有明确接点/按键或受支持的替代路径。
- 串阻、共模器件和 ESD 按确切 PHY/连接器参考设计与测试需求选用，不机械照搬开发板 BOM。
  开发板与成品案例见 [布局约定](pcb-layout-conventions.md) §7.8/§7.10。

## 选型成本档位(Part Cost Tier)

### 候选表与实时选型

- [standard-parts.json](standard-parts.json) 是可复用候选快照；按条目证据区分 source-only、
  offline-verified 与 live-verified。已有 UUID 不保证当前库存、价格、封装或型号仍满足新设计。
- 可从候选表或重新检索开始。复用前核对确切型号、变体、引脚、封装与当前需求；库存/成本是决策依据时，
  查询当前来源并记录时间。现有库器件满足要求时直接复用，自建库只用于实际缺项或错误修复。
- 不为追求最低价强制每次比价，也不为复用历史 UUID 排除更合适的器件。工具见 [器件选型](part-selection.md)。

### 制造服务、基础库与批量

- 先按已知装配方式选择供应渠道。选择 JLC SMT 时比较 Basic/Extended、上料费、库存和装配服务范围；
  手焊、混装或其他供应商方案不受 JLC SMT 清单限制。
- 电气规格与制造可行性优先；Basic 不是强制条件，历史分类/数量不代表当前目录。
  库存与报价只证明查询时点，不保证后续量产供货。
- 已知本轮批量时用该批量评估供货，计入单板用量及必要损耗。尚未决定量产规模的原型可记录合理假设，
  无需为填写最终产量阻塞设计；投产或放量前重新核实。

## 装配与布局形态(Assembly & Placement)

### 单面与双面

- 按尺寸、外壳净空、连接器操作、返修和贴装成本决定是否双面放置。
  双面可能减少面积，但收益由实际几何决定；不能预先承诺固定百分比。
- 双面设计核对器件高度、对侧机械干涉、回流工艺和测试点可达性。单面/双面器件布局与铜层数分别决定。

### 封装与焊接间距

- 按用户已知设备、装配服务与返修需求选封装。手焊可优先较易操作的封装，但 0603 不是通用下限；
  0402/QFN 的可行性取决于设备、经验、焊盘与工艺。
- 间距使用实际 courtyard、器件高度、烙铁/热风可达性及厂商工艺要求；固定 `assembly-gap` 只是工具参数。
  产线贴片同样需核对封装和工艺，不能视为任意小封装都可用。
- 常规选择可记录假设并继续；只有不同装配方式会实质改变可交付结果、且现有信息不足时再询问。
