# v1.10.0 有限验收基准

## 用户范围决定

2026-10-11，在明确提出 v1.10.0 后，用户指示：“最近刚验证过吧 就不验证了 直接发”。
本次据此复用最近的软件验证与定向现场记录，按 `cli-fixes` 范围发布 v1.10.0，
`full-design-e2e` 延期至 `follow-up`。不重跑完整基础批次或需求到成品回归，不把失败改为通过。
该决定只绑定本版本，不改变其他版本的默认验收要求。

## 候选与输入

产品源码基线为 dev 提交 `46dc97bfcbc97809915d9c414d4c9891a075db2c`。
最近验证使用同一隔离候选的 v1.10.0-dev.1；正式候选只同步版本、Changelog 和发布材料，
未纳入工作区其他未提交代码。CLI、daemon、连接器、npm/lock 与 Skill 正式版本统一为 1.10.0。

有限回归使用获准的 ceshi 专用测试工程、一个临时电阻与非零原点五边形板框。
现场身份、库资产、原始日志及私有定位器数据不公开；公开测试夹具使用合成非对称板。
默认完整设计输入仍为 [ESP32-S3 最小点灯板](../../../test-case-esp32-blink.md)第一节原始需求，
文件 SHA256 为 `21bd4682110228de90ee71a8402680eb7668dad5bb7557d44d368d5ff4cd118c`；本次未执行该完整流程。

## 环境与阈值

最近原生测试环境为 macOS arm64、Web EDA 4.1.71，指定窗口 CLI/daemon/连接器精确同版 dev.1。
其他旧窗口不参与新候选证据。五平台 CLI 交叉构建不代表五平台运行时验证。

有限用例 M1/F1/F2/E1/L1/N1/R1 的含义以本目录 test-cases.md 为准，分别验证软件契约、
保存重载回执、采集事实、实际 SVG、丝印读取、图片拒绝与临时对象恢复；它们不是完整设计用例的补签。
图像缺测、unknown 和 known-empty 必须保留真实状态，实际渲染不得改变输入坐标。
图册生成、软件发布、电路正确性、布局确认、布线、DRC 与制造验收分别记录。

完整 B00–B10、完整设计和制造验收不在本次通过范围。已有工程创建失败、官方截图空白、
测试夹具 Netlist Error、导航超时及未执行项均保留在报告中。
