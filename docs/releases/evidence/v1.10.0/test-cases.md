# v1.10.0 有限 CLI/工作流用例

以下 ID 只定义本次用户批准的有限范围；不沿用完整电路验收中的同名判据。
复用同一源码候选刚完成的测试与现场记录，本次发布不重复执行它们。

| ID | 范围 | 输入、步骤与判据 |
|---|---|---|
| M1 | 软件与候选绑定 | 对隔离 dev 基线完成 Go、连接器、Skill/协作入口、发布脚本及 local-dev 资产验证；正式版只改版本与发布材料，不混入其他未提交代码。 |
| F1 | 保存重载回执 | 空板、临时 fixture 与清理后各一次真实 save→close→open→fresh readiness；saved:true、身份与阶段时间/请求 ID 完整。失败阶段、保存失败及超时由自动反例覆盖。 |
| F2 | PCB dump 采集 | 核对四份落盘 JSON 的字节数、SHA256、工程/文档身份和 sidecar；空库存保持 known-empty，不可读板框保持 unknown，不编造默认值；身份漂移和缺测由自动反例覆盖。 |
| E1 | 实际 SVG | 从 fresh dump 离线生成 actual SVG，metadata 绑定输入哈希，渲染前后源字节不变；合成非对称板自动覆盖非零原点、底面镜像、旋转焊盘、通孔与真实文字，候选图不能冒充 actual。 |
| L1 | 丝印事实 | fresh 读取临时器件的位号、Device、Footprint，实测 lineWidth、value 可见性和 keyVisible，保留 getter 来源；未知 getter/零值及自由文字等只按实际自动覆盖记录。 |
| N1 | stage 与图片失败传播 | 核对六份 JSON 加一份 PNG 的落盘哈希/身份；现场单色空白 PNG 必须失败。自动反例覆盖缺图、坏图、哈希不符、身份漂移、显式重复与同字节新采集；不要求本轮补签成功官方截图。 |
| R1 | 精确清理与恢复 | 仅删除本轮一个器件、一个板框；保存重载并回读，与原空板语义哈希、空库存和 availability 一致。 |
| E2E | 延期 | 完整 B00–B10、ESP32-S3 原始需求到原理图/两层 PCB 成品、整板布线、DRC 与制造验收未执行完成，保留 not-run，留待 follow-up。 |
