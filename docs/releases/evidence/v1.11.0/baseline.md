# v1.11.0 有限验收基准

## 用户范围决定

2026-10-14，用户在得知本轮 ESP32-S3 演示是"边修工具边跑"、不能直接作为完整 E2E 证据后，
在给出的三个选项中明确选择"有限范围发 v1.11.0"。本次据此按 `cli-fixes` 范围发布 v1.11.0，
`full-design-e2e` 延期至 `follow-up`。有限用例全部在冻结候选上重新现场执行，不复用旧候选结果；
完整设计 E2E 不补签。该决定只绑定本版本，不改变其他版本的默认验收要求。

## 候选与输入

产品源码候选为 dev 提交 `699d140`（v1.10.0 之后 32 个提交）。连接器运行时自 v1.10.0 起有改动
（页面可见性上报、删除级联、删除必须显式 id、bridge-check 孤桩判据、导入空操作核验等），
按版本规则递增 minor；CLI/daemon、连接器、npm/lock 与 Skill 正式版本统一为 1.11.0。
现场 CLI/daemon 由该候选构建（`v1.10.0-32-g699d140-dirty`，dirty 仅为 `make eext` 产生的未提交
连接器版本号）；连接器为同一源码构建的开发包，经 IndexedDB 热重载装入（现场版本 1.10.7），
`extension/src` 在候选提交后无改动。正式包只同步版本号、Changelog 与发布材料。

现场使用获准的 ceshi 专用测试工程，其中是本轮演示生成的 ESP32-S3 最小点灯板（单页原理图、
两层 PCB，10 个器件）。演示从[最小点灯板](../../../test-case-esp32-blink.md)第一节原始需求出发，
由 Agent 自行选型，文件 SHA256 为 `21bd4682110228de90ee71a8402680eb7668dad5bb7557d44d368d5ff4cd118c`。
工程身份、原始日志与本地路径不公开。

## 环境与阈值

macOS arm64，Web EDA 4.1.71（V4 主线，推荐基线 4.1.60），EDA 标签页前台可见。
有限用例 M1/F1/F2/E1/L1/N1/R1 的含义以本目录 test-cases.md 为准，覆盖本版修复的软件契约、
原理图门禁、PCB 检查与采集、导入与 DRC、原理图整页重建、过期队列拒绝和清理状态；
它们不是完整设计用例的补签。阈值：严格门禁 PASS、原生 DRC passed、`pcb check` 0 ERROR、
保存重载前后语义哈希一致、拒绝路径零写入。

完整 B00–B10、完整设计与制造验收不在本次通过范围。
